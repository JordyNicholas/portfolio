# Documentation

Docs follow [Diátaxis](https://diataxis.fr/): four types, four jobs.

| Type | Job | Where |
| --- | --- | --- |
| **Tutorials** | Learning-oriented — take you through a first successful run | [tutorials/](tutorials/) |
| **How-to guides** | Task-oriented — solve a concrete problem | [how-to/](how-to/) |
| **Reference** | Information-oriented — facts, APIs, inventories | [reference/](reference/) |
| **Explanation** | Understanding-oriented — why we built it this way | [explanation/](explanation/) |

Start here if you are new: [tutorials/getting-started.md](tutorials/getting-started.md).
